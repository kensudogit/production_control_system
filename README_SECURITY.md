# セキュリティに関する重要な注意事項

## OpenAI APIキーの管理

本システムのAI予測機能では、OpenAI APIキーを使用します。
**APIキーは絶対にコードに直接記述しないでください。**

### 正しい使用方法

1. **環境変数ファイルの作成**
   ```bash
   cd frontend
   cp .env.example .env
   ```

2. **APIキーの設定**
   `.env`ファイルを編集：
   ```env
   VITE_OPENAI_API_KEY=your-actual-api-key-here
   ```

3. **`.env`ファイルはコミットしない**
   - `.gitignore`に既に追加済みです
   - 誤ってコミットしないよう注意してください

### 誤ってAPIキーをコミットしてしまった場合

1. **即座にAPIキーを無効化**
   - https://platform.openai.com/api-keys で該当キーを削除

2. **新しいAPIキーを生成**

3. **コミット履歴からの削除**
   - 詳細は `REMOVE_SECRET_FROM_HISTORY.md` を参照

### GitHubのSecret Scanning

GitHubは自動的にシークレットをスキャンし、検出された場合はプッシュをブロックします。
これはセキュリティ機能であり、誤検出ではありません。

### 本番環境での設定

本番環境では、環境変数管理サービスを使用してください：
- **Vercel**: プロジェクト設定の「Environment Variables」
- **AWS**: Secrets Manager
- **Azure**: Key Vault
- **GCP**: Secret Manager

## その他のセキュリティベストプラクティス

1. **パスワードの管理**
   - デフォルトパスワードは必ず変更
   - 強力なパスワードを使用
   - パスワードマネージャーを活用

2. **JWTシークレット**
   - 本番環境では強力なランダム値を生成
   - 環境変数で管理

3. **データベース認証情報**
   - 環境変数で管理
   - `.env`ファイルをコミットしない

4. **定期的なセキュリティ監査**
   - 依存関係の脆弱性チェック
   - コードレビューでのセキュリティチェック
